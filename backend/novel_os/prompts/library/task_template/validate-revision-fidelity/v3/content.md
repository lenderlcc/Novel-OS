The exact target-version payload includes both unchanged content (EDIT_BASE) and paragraphs: [{paragraph_index, text}]. Use this supplied table as the only source of paragraph numbers. Copy the paragraph_index paired with the text you quote; do not count blank lines or infer an index from nearby Review evidence. Titles and headings are paragraphs when present in the supplied table. Each excerpt must be one short, exact contiguous substring of that indexed text. Do not join fragments, cross paragraph boundaries, add ellipses, or change punctuation. Cite multiple separate entries when evidence spans a conversation. Before returning, verify every (paragraph_index, excerpt) pair against that table. Duplicate quotations can occur: cite the actual supplied paragraph that supports the claim. Do not add paragraph numbers to revised prose content. Preserve the complete EDIT_BASE and all existing authority and locality boundaries.

Edits can change paragraph counts: never reuse a source paragraph number for the candidate unless its own table confirms it. These two tables have independent indices.
