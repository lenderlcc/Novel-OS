# NOVEL-008 — Writing Agent + Chapter Draft Production

**Priority:** P0  
**Depends On:** NOVEL-001~007

## Goal

```text
Approved ChapterPlan
→ CP-005
→ Writing Agent
→ WritingResult
→ ChapterVersion DRAFT
→ Deterministic Check
```

## Writing Agent Autonomy

### Autonomous
- wording
- actions
- local detail
- dialogue expression
- scene interaction
- transitions
- local rhythm

### Proposal Allowed
- minor new facts
- non-core supporting detail

### Not Allowed
- major plot turn
- core character change
- world rule change
- major ability / history
- anything altering approved direction

## WritingResult

- content
- scene_execution
- introduced_elements
- proposed_new_facts
- plan_deviations
- unresolved_questions
- assumptions
- knowledge_risk_flags
- confidence

## Writing Skills v1

- Scene Execution
- Dialogue
- Character Voice
- Narrative Rhythm
- Natural Prose

Natural Prose 重点预防：
- Over Explanation
- Emotion Labeling
- Uniform Rhythm
- Template Transition
- Dialogue Functionalization
- Excessive Closure
- Over-signposting

## Critical Rules

- Plan defines intent/constraints, not prose to expand line-by-line
- Writer not see all future plans
- Global Canon ≠ Character Knowledge
- Draft not Canon
- new facts are proposals
- major deviation blocks normal pipeline
- new generation creates new ChapterVersion
- approved_version unchanged

## Acceptance

必须验证：
- no approved plan → no writing
- stale plan/context blocked
- draft version creation
- approved version safety
- minor deviation allowed
- major deviation blocks
- proposed fact not Canon
- real model draft generation works
